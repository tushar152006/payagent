# HACKATHON WINNING WORKSPACE CONFIGURATION

This workspace is primed for competitive hackathons. Every recommendation, architectural choice, code generation, and pitch document must adhere to the **Hackathon Grandmaster Framework**.

---

## The 3 Operating Pillars

### 1. Ponytail Engineering Discipline (`.agents/rules/ponytail.md`)
- **"The best code is the code you never wrote."**
- Before adding any package or writing complex logic, ask:
  > *"Who will use this? Is this solving my main core problem, or is this just a good-to-have feature?"*
- If it is "good-to-have", **cut it**. Only build the core problem solver.
- Never write fragile architectures that can crash during a live judge demo. Provide reliable mock fallbacks for all external APIs.

### 2. Hackathon Grandmaster Workflow (`.agents/skills/hackathon-grandmaster/SKILL.md`)
Follow the 11-time hackathon winner methodology:
1. **Understand the Metrics:** Decode the scoring rubric and sponsor bounties first.
2. **Quantify the Problem:** How big is it? How frequent is it? How much money/time is burning?
3. **Evidence-First Discovery:** Back the problem with real-world proof (Forbes, Reddit complaints, news, industry reports, surveys).
4. **Distill the USP:** Formulate a razor-sharp Unique Selling Proposition.
5. **The 6-Slide Pitch Engine:** Problem ➔ Evidence ➔ Cost of Problem ➔ Solution ➔ Before & After ➔ Team.

### 3. Impeccable Design Quality (`.agents/skills/impeccable/SKILL.md`)
- Reject all generic "AI slop" (overused purple-to-blue gradients, plain Inter font cards, low contrast).
- Build production-grade, aesthetically stunning UIs with distinctive typography, intentional palettes, crisp borders, and micro-interactions.
- Judges judge UI in the first 10 seconds—make every screen look like an award-winning product.

### 4. Gemini Argon Deep Recon Protocol (Human-in-the-Loop Intelligence Scout)
- **Role of Gemini Argon:** Dedicated Deep Research Scout for real-time evidence, Forbes/news articles, Reddit complaints, verified statistics, and competitor gaps.
- **Protocol:** Whenever entering Stage 2 (Evidence & Sizing) or preparing Stage 5 (Judge Defense & Pitch Evidence), Antigravity will format an optimized **`[ARGON SCOUT PROMPT]`**.
- The user runs the prompt in Gemini Argon and pastes the findings back here. Antigravity will immediately synthesize and inject them into the project architecture and the 6-slide deck.
